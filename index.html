What is shared, and what to change

  • All copy, portfolio entries, pricing and FAQ live once in shared/site-data.js — edit there and all six update.
  • The 3D viewer is shared/jewelry-3d.js: every ring, signet and pendant is generated in code, so there are no model files to host.
  • The contact form is a working UI with validation and a drag-and-drop zone, but it is not wired to a backend — nothing is transmitted.
  • Company name, figures, photographs and contact details are placeholders. See README.md for the replacement checklist.
Static build — no backend, no build step. Open any variant directly or serve the folder over HTTP.
